 Projeto Cinelista

Desenvolvi este projeto durante o curso da EBAC para facilitar a consulta de filmes, reunindo informações de uma API REST externa em uma interface responsiva.

Implementei a interface e o consumo da API com Next.js, JavaScript, HTML e CSS, com deploy contínuo na Vercel.

Teste a aplicação: [Cinelista](https://projeto-cinelista.vercel.app/)

Para executar localmente, clone o repositório e instale as dependências:

```bash
git clone https://github.com/GuilhermeAZampar/Projeto_Cinelista.git
cd Projeto_Cinelista
npm install
npm run dev
```

Acesse http://localhost:3000/. Caso a API utilizada exija uma chave de acesso, configure as variáveis de ambiente antes de iniciar.
